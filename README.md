## 📁 프로젝트 구성

### 1. `python/`
터미널에서 실행되는 벚꽃 애니메이션입니다.  
꽃잎과 반짝이가 떨어지는 효과를 콘솔 화면에서 볼 수 있습니다.

- 실행 환경: Python
- 실행 파일: `python/sakura.py`

```bash
python sakura.py
```
<br />
<br />

### 2. html/
브라우저에서 실행되는 벚꽃 애니메이션입니다.
Canvas를 활용하여 웹 환경에서 벚꽃이 자연스럽게 떨어지는 효과를 구현했습니다.

- 실행 환경: HTML / CSS / JavaScript
- 실행 파일: `html/sakura.html`

👉 파일을 브라우저로 열면 바로 확인할 수 있습니다.

<br />
<br />

### 3. `vue-sakura/`
Vue 기반으로 벚꽃 애니메이션을 구현한 프로젝트입니다.
기존 HTML 버전을 컴포넌트 구조로 분리하여 Vue 환경에 맞게 확장했습니다.

- 실행 환경: Vue + Vite
```bash
npm install
npm run dev
```
👉 실행 후 http://localhost:5173에서 확인 가능합니다.

<br />
